Thredle :- Core PHP Project
Website link :- https://threadle.in
Overview
Thredle is a web-based platform developed in Core PHP and hosted on AWS. It provides a seamless user experience with dynamic content rendering and optimized performance.

Features
Built with Core PHP (no frameworks)
Hosted on AWS EC2 with an optimized LEMP stack
Secure MySQL database integration
Implements SSL/TLS using Let's Encrypt

Configure Database
Import the provided .sql file into MySQL
Update config.php with database credentials
